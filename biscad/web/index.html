01 — Agents

Agents write the part. You see what they did.

A real B-rep kernel with an interface for models, and outputs for the people who supervise them.

A

Code is the model

Every part is a build123d program. Declare params = {...} and override any value per call. You get configurations with no extra work.

B

Stable face ids

Faces and edges get ids like p0/f3. The viewer, the API and MCP use the same id. Click a face and paste it into a prompt.

C

Agents can see

Headless renders with face ids drawn on. Four views in one image. The model checks its work before it tells you it is done.

D

Text to CAD

Send a sentence to POST /v1/agent. Claude writes the script, the kernel builds it, Claude reads the renders and fixes errors.

E

Real B-rep

OpenCascade solids, not meshes. Export STEP for Fusion or SolidWorks. Measure, section, check mass, run DFM and diff two versions.

F

Nothing is lost

Every build is a version with a parent. Branch from any version. Diff any two. Import STEP, BREP or STL to start from a supplier part.

05 — REST API

Script in. STEP out.

Build a part, save it as a version, download the STEP. Three calls.

# 1 · build (stateless): summary + scene, nothing stored
curl -s https://api.biscad.dev/v1/build \
  -H "Authorization: Bearer $BISCAD_KEY" \
  -H "Content-Type: application/json" \
  -d '{"script": "from build123d import *\nparams = {\"w\": 40}\nresult = Box(params[\"w\"], 30, 6)", "params": {"w": 60}}'

# 2 · save it as a document; the response holds version.id
curl -s https://api.biscad.dev/v1/documents \
  -H "Authorization: Bearer $BISCAD_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "plate", "script": "from build123d import *\nresult = Box(60, 30, 6)"}'

# 3 · export
curl -s https://api.biscad.dev/v1/versions/$VERSION_ID/export/step \
  -H "Authorization: Bearer $BISCAD_KEY" -o plate.step
import os, requests

API = "https://api.biscad.dev"
H = {"Authorization": f"Bearer {os.environ['BISCAD_KEY']}"}

script = """
from build123d import *
params = {"w": 40, "h": 30, "t": 6}
result = Box(params["w"], params["h"], params["t"])
"""

# 1 · build (stateless)
r = requests.post(f"{API}/v1/build", headers=H,
                  json={"script": script, "params": {"w": 60}}).json()
print(r["ok"], r["summary"]["volume"])

# 2 · save as a document → version
doc = requests.post(f"{API}/v1/documents", headers=H,
                    json={"name": "plate", "script": script}).json()
vid = doc["version"]["id"]

# 3 · export STEP
step = requests.get(f"{API}/v1/versions/{vid}/export/step", headers=H)
open("plate.step", "wb").write(step.content)
const API = "https://api.biscad.dev";
const H = { Authorization: `Bearer ${process.env.BISCAD_KEY}`, "Content-Type": "application/json" };

const script = `from build123d import *
params = {"w": 40, "h": 30, "t": 6}
result = Box(params["w"], params["h"], params["t"])`;

// 1 · build (stateless)
const built = await fetch(`${API}/v1/build`, {
  method: "POST", headers: H, body: JSON.stringify({ script, params: { w: 60 } }),
}).then(r => r.json());
console.log(built.ok, built.summary.volume);

// 2 · save as a document → version
const { version } = await fetch(`${API}/v1/documents`, {
  method: "POST", headers: H, body: JSON.stringify({ name: "plate", script }),
}).then(r => r.json());

// 3 · export STEP
const step = await fetch(`${API}/v1/versions/${version.id}/export/step`, { headers: H });
await require("fs/promises").writeFile("plate.step", Buffer.from(await step.arrayBuffer()));

08 — Questions

The short answers.

Is it really build123d?

Yes. Your script runs on stock build123d and OpenCascade. A script that works on your machine works here, inside the sandbox. Allowed imports: build123d, numpy, math and the standard numeric modules. Scripts get no file or network access.

Can it make a part from a sentence?

Yes. Send POST /v1/agent with a prompt. Claude writes the script, the kernel builds it, and Claude checks the four-view render. You need an API key. The free plan includes 10 runs a month.

Can I import STEP?

Yes. POST /v1/import takes STEP, BREP or STL. It returns a document with stable face ids. You can then measure, section, render or change it.

Is my code private?

Yes. Documents are private to your API key on all plans. Each version has an id that nobody can guess, and it works as a share link. Each script runs in its own worker with memory and CPU limits.

Can I self-host?

Yes. BISCAD is open source. Run docker run -p 8000:8000 biscad. For a public URL, ./deploy/public.sh opens a Cloudflare quick tunnel.

Why is it so cheap?

The kernel is open source, so there are no licence fees. Workers fork from a warm process, so a build costs a fraction of a CPU-second. Agents are not seats, so we do not charge per seat.

Does it work with Claude, Cursor and ChatGPT?

Yes. It works with any client that speaks MCP over HTTP: Claude Code, Claude Desktop, Cursor and ChatGPT connectors. Other tools can use the REST API and llms.txt.
